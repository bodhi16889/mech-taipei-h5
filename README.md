# 台北機甲拆除模擬器 · 工程拆除切片

> 2087 年，退役機甲散落在台北街廓。你是外包拆除工：切開裝甲、洩掉液壓、繫留承重柱，
> 在反應爐熔毀前取出核心，然後在市政合約與黑市報價之間算清楚這一單划不划算。

單一 HTML 檔的 Three.js 可玩切片，依《台北機甲拆除模擬器》GDD 的核心循環實作。
**沒有任何外部模型或貼圖**：機甲、街景、音效全部程序化生成。

- 線上版：<https://bodhi16889.github.io/mech-taipei-h5/>
- 手機可直接開（PWA 可加到主畫面）

## 這是 GDD 的哪一段

| GDD 章節 | 本切片實作 |
|---|---|
| 3. 核心循環 | 接單 → 現場拆卸 → 結算／升級 → 下一個合約（可連續玩完 4 單） |
| 4.1 結構分層 | 裝甲板 → 紅／藍／黃管線 → 承重柱 → 動力核心（分層且互相牽制） |
| 4.2 工具庫 | 電漿切割器、重力繫留、冷凍凝膠、聲納掃描；外骨骼噴射（Space） |
| 5. 關卡 | 4 張合約對應 4 個 GDD 關卡（忠孝東路／西門町／101／社子島） |
| 6. 經濟 | 回收零件計價、履約獎金、工安罰款、工具升級（切割／絞盤／防護） |
| 2. 美術／音效 | 夜間台北剪影、霓虹底光、程序化材質；WebAudio 合成打擊與爆炸 |

**不是** GDD 的全部：沒有 UE5 的動態網格切割、沒有 Chaos 應力解算、沒有 18 個月的內容量。
切割是「進度條 → 部件狀態機」，傾倒是事件而不是物理模擬。

## 怎麼玩

1. 選一張合約 → 進場。
2. 走到機甲旁，先按 <kbd>E</kbd> 開**洩壓閥**（沒洩壓就切紅管＝爆炸）。
3. <kbd>1</kbd> 電漿切割，**按住左鍵**切部件：
   - 胸甲兩片切開 → 核心暴露，**60 秒倒數**開始。
   - 承重柱**沒繫留就切** → 機甲往旁邊倒，砸毀地標，扣 35% 酬勞。
4. <kbd>2</kbd> 重力繫留：先點部件（繫留），再切它，切下的部件自動吊回回收區計價。
5. <kbd>3</kbd> 冷凍凝膠：撲滅爆炸引起的火。
6. <kbd>4</kbd> 聲納（按住）：確認管線與部件位置。
7. 核心在 7.5 公尺高：**噴射上去**（按住 <kbd>Space</kbd>），靠近按 <kbd>E</kbd> 取出。
8. 配額達標 + 核心到手 → 按 <kbd>E</kbd> **收工** → 結算、買升級、接下一個合約。

| 桌機 | 動作 |
|---|---|
| <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> | 移動 |
| 滑鼠 | 轉視角（點擊畫面鎖定） |
| <kbd>Shift</kbd> | 加速 |
| <kbd>Space</kbd> | 外骨骼噴射 |
| 左鍵 | 使用當前工具（切割需按住） |
| <kbd>1</kbd>~<kbd>4</kbd> | 切換工具 |
| <kbd>E</kbd> | 洩壓／取核心／收工 |
| <kbd>R</kbd> | 重新載入 |

手機：左下虛擬搖桿移動、右側拖曳轉視角、右下「切割」按住、「E」鍵對應洩壓／核心。

## 執行

```bash
python -m http.server 8099
# 開 http://127.0.0.1:8099/
```

需要網路載入 Three.js CDN（`three@0.160.0`）。不要直接雙擊 `index.html`（`file://` 會被 CORS 擋）。

## 驗證

```bash
python verify_v3.py --page index.html
```

無頭 Chromium 實際操作並斷言 16 項行為：合約板、機甲生成、洩壓、安全切紅管、
胸甲→核心暴露、熔毀倒數、地面取不到核心、噴射可取、繫留切承重柱不倒、配額、
收工結算帳目、升級扣款、未繫留傾倒罰款、未洩壓爆炸、真實滑鼠切割路徑、手機搖桿與版面、
reduced-motion，以及 console 零錯誤。

## 已知限制

- 沒有存檔：重新整理即重來（資金與升級不保留）。
- 切割是進度條模型，不是自由網格切片；沒有真實的應力解算。
- 場景為程序化方塊與剪影，不是寫實台北。
- 只有 4 張合約、1 種機甲藍圖骨架（以尺寸與額外部件區分）。
